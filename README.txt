# JP Salon — Premium Website

## Files
- `index.html` — complete responsive website
- `images/logo.png` — salon logo
- `images/salon-facial.png` — supplied salon photo
- `images/hair-art.png` — supplied hair styling photo
- `images/salon-interior.png` — supplied interior photo

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the complete `images` folder.
3. Open Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save. Your website will get a GitHub Pages URL.

## Easy photo replacement
Keep the same filenames inside `images/` and replace the pictures. No HTML editing is needed.
